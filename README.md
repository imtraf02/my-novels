# my-novels

Workspace viết truyện dài tập bằng pipeline AI:

- **`.opencode/skills/`** — bộ skill dùng chung mọi bộ truyện: `chapter-summary`, `continuity-check`, `glossary-sync`, `style-check`, `audio-export`, `scene-illustration-prompts`
- **`series/ta-lap-giao/`** — *Ta Chỉ Là Chưởng Môn Yếu Kê, Đệ Tử Sao Toàn Là Thiên Kiêu?* (hài / xuyên không / yếu kê lưu): bible đầy đủ, bản thảo, tóm tắt phân tầng, kịch bản audio TTS và prompt ảnh minh họa
- **`references/`** — tư liệu phân tích phong cách tham chiếu

Quy ước cấu trúc mỗi series nằm trong `series/<ten-bo>/bible/conventions.md` — mọi skill đọc trước khi chạy.
